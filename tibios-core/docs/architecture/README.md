# TibiOS Architecture

**Status: Architecture v1.0 (Frozen)**

## Normative documents

`00-philosophy.md`, `02-project-structure.md`, `11-runtime.md`, `13-object-model.md` through `31-federation.md`.

These define the architecture. Every architectural question TibiOS answers is answered in exactly one of these documents.

## Reference documents

`GLOSSARY.md` — term index, points at owning documents, defines nothing.
`diagrams/` — official Mermaid diagrams, git-versioned and authoritative. Rendered or exported forms are derived documentation, never the reference.

## Rule

Changes after v1.0 must preserve backwards consistency with the frozen model, or explicitly open Architecture v1.1. No normative document is edited casually once tagged.
